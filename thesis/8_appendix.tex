приведён на рис.~\ref{fig:bench_photos}. Каждое изображение соответствует
определённому состоянию конечного автомата каскадной системы обработки,
описанного в подразделе~3.1, и демонстрирует визуальную индикацию текущего
режима на периферийных устройствах стенда.

На представленной сетке снимков отображены следующие режимы:
\begin{itemize}
	\item режим ожидания (рис.~\ref{fig:bench_sleep})~--- состояние \texttt{DEEP\_SLEEP},
	      минимальное энергопотребление до срабатывания аппаратного компаратора;
	\item режим записи (рис.~\ref{fig:bench_record})~--- состояние \texttt{RECORD},
	      процесс захвата аудиопотока с MEMS-микрофона INMP441 в буфер DMA;
	\item извлечение признаков (рис.~\ref{fig:bench_mfcc})~--- состояние \texttt{MFCC},
	      расчёт матриц спектральных коэффициентов с использованием инструкций ESP-DSP;
	\item нейросетевой инференс (рис.~\ref{fig:bench_inference})~--- состояние \texttt{INFERENCE},
	      выполнение квантованной модели DS-CNN интерпретатором TFLite Micro;
	\item индикация отсутствия полезного сигнала (рис.~\ref{fig:bench_res_silence})~--- состояние \texttt{RESULT},
	      алгоритм классифицировал входной фрейм как фоновый шум или тишину;
	\item индикация распознанной команды (рис.~\ref{fig:bench_res_command})~--- состояние \texttt{RESULT},
	      фиксация положительного исхода классификации и вывод имени команды на дисплей.
\end{itemize}

\appsection{Д}{Ключевые фрагменты прошивки микроконтроллера}

\subsection*{Д.1. Переход в режим глубокого сна (vad\_sleep.c)}

Порядок операций критичен: деинициализация периферии и изоляция
GPIO предшествуют настройке источника пробуждения. Нарушение
порядка приводит к ложному срабатыванию EXT1 из-за переходных
процессов на выводах RTC GPIO в момент перехода в режим сна.

\begin{verbatim}
void vad_sleep_enter(bool enable_led) {
    if (enable_led) {
        rtc_gpio_init(SLEEP_LED_GPIO);
        rtc_gpio_set_direction(SLEEP_LED_GPIO, RTC_GPIO_MODE_OUTPUT_ONLY);
        rtc_gpio_set_level(SLEEP_LED_GPIO, 1);
        rtc_gpio_hold_en(SLEEP_LED_GPIO);
    }

    rtc_gpio_init(SOUND_GPIO);
    rtc_gpio_set_direction(SOUND_GPIO, RTC_GPIO_MODE_INPUT_ONLY);
    rtc_gpio_pullup_en(SOUND_GPIO);
    rtc_gpio_pulldown_dis(SOUND_GPIO);

    ESP_ERROR_CHECK(esp_sleep_enable_ext1_wakeup(
        1ULL << SOUND_GPIO, ESP_EXT1_WAKEUP_ANY_LOW));

    esp_deep_sleep_start();
}
\end{verbatim}

\subsection*{Д.2. Инициализация инференса (kws.cpp)}

Арена тензоров размером 140~КБ обязательно размещается во
внутреннем SRAM микроконтроллера (флаг
\texttt{MALLOC\_CAP\_INTERNAL}), поскольку аппаратное
SIMD-ускорение библиотеки ESP-NN корректно работает только с
этим типом памяти.

\begin{verbatim}
static constexpr int kArenaSize = 140 * 1024;
static uint8_t *tensor_arena = nullptr;

esp_err_t kws_init(void) {
    model = tflite::GetModel(g_model_data);
    if (model->version() != TFLITE_SCHEMA_VERSION) return ESP_FAIL;

    static tflite::MicroMutableOpResolver<8> resolver;
    resolver.AddConv2D();
    resolver.AddDepthwiseConv2D();
    resolver.AddFullyConnected();
    resolver.AddMean();
    resolver.AddReshape();
    resolver.AddQuantize();
    resolver.AddDequantize();
    resolver.AddSoftmax();

    tensor_arena = (uint8_t *)heap_caps_malloc(
        kArenaSize, MALLOC_CAP_INTERNAL | MALLOC_CAP_8BIT);
    if (!tensor_arena) return ESP_ERR_NO_MEM;

    static tflite::MicroInterpreter static_interp(
        model, resolver, tensor_arena, kArenaSize);
    interpreter = &static_interp;

    if (interpreter->AllocateTensors() != kTfLiteOk) return ESP_FAIL;

    input_tensor = interpreter->input(0);
    output_tensor = interpreter->output(0);
    return ESP_OK;
}
\end{verbatim}

\subsection*{Е.1. Архитектура DS-CNN (ds\_cnn.py)}

Параметризованная реализация архитектуры, используемая для
обучения 134~различных конфигураций сетки $(F, B)$ из
подраздела~3.4.

\begin{verbatim}
def _ds_block(x, filters, kernel, name):
    """Блок разделимой свёртки: DW -> BN -> ReLU -> PW -> BN -> ReLU."""
    reg = _regularizer()
    x = layers.DepthwiseConv2D(
        kernel_size=kernel, padding="same", strides=(1, 1),
        depthwise_regularizer=reg, use_bias=False, name=f"{name}_dw"
    )(x)
    x = layers.BatchNormalization(name=f"{name}_dw_bn")(x)
    x = layers.ReLU(name=f"{name}_dw_relu")(x)
    x = layers.Conv2D(
        filters=filters, kernel_size=(1, 1), padding="same",
        strides=(1, 1), kernel_regularizer=reg, use_bias=False,
        name=f"{name}_pw"
    )(x)
    x = layers.BatchNormalization(name=f"{name}_pw_bn")(x)
    x = layers.ReLU(name=f"{name}_pw_relu")(x)
    return x


def build_ds_cnn(input_shape, num_classes, cfg):
    reg = _regularizer()
    inputs = tf.keras.Input(shape=input_shape, name="mfcc_input")

    x = layers.Conv2D(
        filters=cfg["first_conv_filters"],
        kernel_size=cfg["first_conv_kernel"],
        strides=cfg["first_conv_stride"],
        padding="same", kernel_regularizer=reg,
        use_bias=False, name="stem_conv"
    )(inputs)
    x = layers.BatchNormalization(name="stem_bn")(x)
    x = layers.ReLU(name="stem_relu")(x)

    for i in range(cfg["num_ds_blocks"]):
        x = _ds_block(x, cfg["ds_filters"], cfg["ds_kernel"],
                      name=f"ds{i+1}")

    x = layers.GlobalAveragePooling2D(name="gap")(x)
    x = layers.Dropout(0.2, name="dropout")(x)
    outputs = layers.Dense(num_classes, activation=None,
                           kernel_regularizer=reg, name="logits")(x)

    return tf.keras.Model(inputs, outputs, name="ds_cnn")
\end{verbatim}

\subsection*{Е.2. Слияние BatchNorm перед QAT (quantize\_qat.py)}

Слияние BN в предшествующий свёрточный слой выполняется перед
вставкой узлов симуляции квантования и обеспечивает численную
устойчивость дообучения, как описано в подразделе~2.5.

\begin{verbatim}
def fold_bn(conv_layer, bn_layer):
    """Слияние BN в предшествующий Conv/DepthwiseConv.

    new_weight = weight * gamma / sqrt(var + eps)
    new_bias   = beta - gamma * mean / sqrt(var + eps)
    """
    gamma, beta, moving_mean, moving_var = bn_layer.get_weights()
    eps = bn_layer.epsilon
    scale = gamma / np.sqrt(moving_var + eps)

    kernel = conv_layer.get_weights()[0]
    if isinstance(conv_layer, tf.keras.layers.DepthwiseConv2D):
        new_kernel = kernel * scale[np.newaxis, np.newaxis, :, np.newaxis]
    else:
        new_kernel = kernel * scale[np.newaxis, np.newaxis, np.newaxis, :]

    new_bias = beta - moving_mean * scale
    return new_kernel.astype(np.float32), new_bias.astype(np.float32)
\end{verbatim}
