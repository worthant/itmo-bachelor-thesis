## Как делать замеры (механика)

### Загрузка модели

1. PlatformIO env с переменной `PLATFORMIO_MODEL_SLUG=<slug>`
2. CMakeLists подхватывает `nn/results/.../<slug>/model_data.c` автоматически
3. Прошить, прогнать `kws_benchmark(100, 5)` (100 рабочих + 5 warmup)
4. Подключиться к SPIFFS, забрать `/spiffs/profile.csv`

### Замер энергии параллельно

1. ESP32-S3-Zero c моделью дёргает GPIO при входе/выходе из INFERENCE
2. ESP32-C3 с INA228 пишет CSV: `timestamp,V,I,phase`
3. Обработка: интегрируем `V*I*dt` по строкам с `phase=INFERENCE`

### Данные INA228 (есть пример)

- Период 60 мс, разрешение ~1 мкА, ~6.3 мА в SLEEP, ~80-90 мА в INFERENCE
- Скрипт обработки уже есть: `scripts/profile_analysis.py`
